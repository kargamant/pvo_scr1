# Snake — аппаратный контракт (HW/SW интерфейс)

Плата: **Nexys A7-100T** (Artix-7 XC7A100T). Ядро: **SCR1** (AXI-мастер) в block-design SoC `nexys4ddr_sopc`.
Всё, что здесь описано, мы задаём сами (змейку пишем сами).

## Карта памяти (существующая + добавляемая)

| Адрес | Слейв | Статус |
|---|---|---|
| `0x0000_0000` | DDR2 (128 MB) | есть |
| `0xF000_0000` | TCM (код исполняется тут) | есть |
| `0xFF00_0000` | soc_id | есть |
| `0xFF01_0000` | UART (axi_uart16550) | есть |
| **`0xFF02_0000`** | **`vga_ctrl` — тайловый фреймбуфер** | добавляем (Фаза 2) |
| **`0xFF03_0000`** | **`ps2_kbd` — клавиатура** | добавляем (Фаза 3) |
| `0xFFFF_0000` | bootloader BRAM (64K) | есть |

## Дисплей — `vga_ctrl` @ `0xFF02_0000`

- Режим: **640×480 @ 60 Hz**, пиксельный клок **25 МГц** (25.175 идеал, 25.0 ок).
- Тайл **16×16 px** → сетка **40×30 клеток**.
- Фреймбуфер: двухпортовый BRAM, **1 слово на клетку** (пишутся младшие 4 бита = индекс палитры).
- Адрес клетки: `0xFF02_0000 + (((y << 6) | x) << 2)`, где `x∈[0,39]`, `y∈[0,29]`
  (**word-per-cell**: одна AXI-Lite запись = одна клетка, без WSTRB-игр; шаг строки 64 клетки).
- Регион: 2048 клеток × 4 байта = 8 КБ (используется до индекса 1895).
- Порт A: запись от CPU @ 30 МГц. Порт B: чтение разверткой @ 25 МГц. CDC — самим dual-port BRAM.
- Палитра (16×12-бит RGB444), фиксированная в v1:

  | idx | цвет | назначение |
  |---|---|---|
  | 0 | чёрный | фон |
  | 1 | зелёный | тело змеи |
  | 2 | ярко-зелёный | голова змеи |
  | 3 | красный | яблоко |
  | 4 | серый | стена/граница |
  | 5 | белый | текст/счёт |
  | 6..15 | резерв | — |

Запись клетки из C:
```c
#define VGA ((volatile unsigned int *)0xFF020000u)
#define VGA_CELL(x,y) VGA[((y)<<6)|(x)]
VGA_CELL(3,5) = 3;   // яблоко (idx 3 = красный) в (x=3,y=5)
```

## Клавиатура — `ps2_kbd` @ `0xFF03_0000`

- Источник: USB-HID host платы → протокол **PS/2** (pin PS2_CLK=F4, PS2_DATA=B2).
- Регистры (offset от базы):
  - `0x00 STATUS` (RO): bit0 = `data_valid` (FIFO не пуст).
  - `0x04 DATA`   (RO): чтение вынимает 1 скан-код из FIFO (16 байт).
- Скан-коды **set-2**. Управление **WASD**: `W=0x1D, A=0x1C, S=0x1B, D=0x23`.
- Отпускание клавиши: приходит `0xF0` затем код → софт пропускает оба байта.

Чтение из C:
```c
#define KBD ((volatile unsigned int *)0xFF030000u)
static inline int kbd_get(void){ return (KBD[0]&1) ? (int)(KBD[1]&0xFF) : -1; }
```

## Тайминг игры
Шаг змейки — по CSR `mcycle` (задержка = скорость/уровень). Частота CPU 30 МГц (`SYS_CLK=30000000`).

## Сборка софта
`MEM=tcm`, `MARCH=rv32im_zicsr_zifencei`, picolibc, линк на TCM (entry `0xF000_0200`).
Загрузка на плату по XMODEM через bootloader (minicom_mcp).
