# Snake on SCR1 / Nexys A7-100T

Подключаем плату к монитору (VGA) и клавиатуре (USB-HID→PS/2) и запускаем змейку
на модернизированном ядре SCR1. Змейку и всю периферию пишем сами.

**Целевой вид v1:** тайловая сетка 40×30, управление WASD, счёт + Game Over, VGA 640×480@60.

Аппаратно-программный контракт (адреса, регистры, палитра): [doc/hw_contract.md](doc/hw_contract.md).

## Структура
```
snake/
  rtl/          RTL периферии (VGA, PS/2)
  sim/          тестбенчи (iverilog)
  constraints/  XDC (пины)
  sw/           игра на C (Фаза 4)
  doc/          контракт/спека
  build_pattern.tcl   сборка Фазы-1 битстрима
```

## Статус по фазам

| Фаза | Что | Статус |
|---|---|---|
| 0 | Стенд, проверка board-flow | — |
| 1 | VGA-развёртка + тестовый паттерн (градиент) | **Битстрим собран, timing MET (WNS +5.46 ns)**; ждёт прошивки+платы |
| 2 | `vga_ctrl` AXI-Lite фреймбуфер (RTL+sim) | **RTL готов, sim PASS** (420k пикс. vs эталон); ждёт интеграции в BD |
| 3 | `ps2_kbd` AXI-Lite клавиатура (RTL+sim) | **RTL готов, sim PASS** (WASD+break через FIFO); ждёт интеграции в BD |
| 4 | Змейка на C (драйверы+игра) | **Собирается в `sw/build/snake.bin`** (7 КБ, TCM, entry 0xF0000200); ждёт железа |
| 5 | Тайминг/полировка | не начато |

**Осталось: интеграция в SoC block design** (добавить `vga_ctrl`+`ps2_kbd` слейвами на smartconnect, +25 МГц выход у clk_wiz, пины VGA/PS2 в XDC проекта). Это единственный шаг, затрагивающий существующий проект `fpga-sdk-prj/nexys4ddr` — делается с подтверждения.

## Софт: сборка
```bash
cd snake/sw && LC_ALL=C make        # -> build/snake.bin
```
Загрузка на плату по XMODEM через bootloader (как coremark/dhry, см. [[minicom-mcp]]).

## Фаза 1 — как проверить

Симуляция тайминга:
```bash
bash snake/sim/run.sh          # ожидается RESULT: ALL PASS
```

Сборка standalone-битстрима (цветной градиент + белая рамка, без SoC):
```bash
cd /home/toast/scr1_sber
LC_ALL=C vivado -mode batch -source snake/build_pattern.tcl
# -> snake/build/vga_pattern_top.bit
```
Прошить, подключить VGA-кабель к монитору: должен появиться плавный
цветовой градиент с белой рамкой по краю экрана, LED[5:0] считают кадры (~60 Гц).
Это подтверждает пиксельный клок, разводку пинов, кабель и синхронизацию монитора
до всякой интеграции с шиной.
